# Cwlwm Field Operations v1.1 Phase 2 — Field Workspace

This update adds the live Field Workspace at `/field`.

## Included
- Prioritized Today route board
- Follow-up and appointment queues
- Representative-aware location scoping
- Territory and search filters
- Location focus panel
- Active appointment / sales context
- Quick disposition and visit-note workflow
- Start/resume sale shortcuts
- External map lookup for addresses
- Responsive mobile field layout
- Role-aware write controls

## Apply
Extract this update over the root of the current Cwlwm Field Operations project and allow files to overwrite.

Then run:

```powershell
npm run build
npm run dev
```

Open `/field` and test with both a representative account and an operations/admin account.
