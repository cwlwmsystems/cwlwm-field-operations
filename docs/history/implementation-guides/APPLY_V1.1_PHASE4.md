# v1.1 Phase 4 — Rep Map UX

This update improves the live rep experience:

- status-colored map pins
- selected-pin emphasis and tooltips
- clearer route line
- map legend for unvisited / visited / follow-up / sale / GPS
- mobile bottom-sheet location workspace
- map and route stop selection automatically opens the mobile location panel
- stronger mobile controls and touch targets

No database migration is required.

After applying:

```powershell
npm run build
npm run dev
```

Test `/field` on desktop and a phone-sized viewport.
